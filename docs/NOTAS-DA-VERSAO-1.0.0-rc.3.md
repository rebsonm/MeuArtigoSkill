## RC.3 source scope and functional limits

- Includes source changes on `main` after the previous immutable RC.1 tag,
  including English methodology-card and documentation corrections.
- Adds guided research next-step choices: A/B/C with pros, cons and one
  contextual recommendation, plus a persistent editable D field and
  explicit Submit answer button where native host controls are available.
  Skills-only hosts without such controls use ordinary text responses.
- Adds documentary GitHub/Zenodo parity checks: consistent source VERSION,
  planned tag and citation, followed by independent verification of the
  exact source archived on Zenodo after an authorized publication.
- Retains Google Drive First preflight, actual source provenance, DEC/TRACE
  and seven independent researcher-controlled scientific gates (PENDING
  until a valid, recorded scientific decision).

## Limitations and release conditions

- These behavioral UI specifications do **not** prove that the active
  ChatGPT host will render native radio inputs, a textarea or a submit
  button for an imported Skill.
- Repository changes alone do not update the currently installed Skill.
  An alternate distribution format is not created by publishing this
  source release.
- The GitHub audit and signed-off experimental ZIP must pass before release.
  Real-host acceptance and independently verified Zenodo DOI/source
  fingerprint remain separate postpublication checks.
- Publishing a GitHub Release can trigger the **enabled GitHub–Zenodo
  integration automatically**. The maintainer has explicitly authorized publishing this RC.3 release,
  including its expected automatic Zenodo archiving. No Zenodo DOI may
  be fabricated before receipt; a normal Git commit alone is not a release.
- No existing GitHub tag or Zenodo record is rewritten. The historical
  RC.1/RC.2 discrepancy is documented but not assumed resolved.
- Third-party methodology PDFs retain their own author/publisher licenses;
  Apache-2.0 covers only eligible software, not all third-party materials.
