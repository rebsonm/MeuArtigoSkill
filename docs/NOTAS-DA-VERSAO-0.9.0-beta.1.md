# Meu Artigo — 0.9.0-beta.1

**Experimental public beta.** This is a software engineering release,
not an independently validated research methodology or a certification of
scientific article quality.

## Changes since v0.8.0-beta.8

- **English-first repository source:** the Skill entrypoint, onboarding
  instructions, research-method documentation, source guidance and
  maintainers' release notes have been migrated to English. Existing
  technical paths and machine-readable IDs remain stable when changing
  them would break older research projects.
- **Automatic conversational language:** the installed assistant is
  instructed to answer substantive direct research messages in the
  researcher's language by default, including Portuguese, English or
  Spanish as appropriate. An explicit user language preference overrides
  automatic choice. The scholarly manuscript language is independently
  governed by the researcher or the target journal.
- **Method-specific research routes:** integrative, systematic and
  problematizing literature reviews; conceptual/theory papers;
  qualitative, quantitative, mixed-method and design-science work.
  These routes share the existing seven genuine researcher review gates.
- **Epistemic safeguards:** separate bibliographic metadata checks,
  passage verification, documented human review and actual empirical
  evidence. Logs and automated checks are not proof of scientific validity.
- **Progressive reference loading:** a smaller Skill entrypoint,
  topic/stage-specific documents, method index and simplified guidance
  for beginners, retaining the same scientific controls.
- **Maintainer controls:** protected-main CI, read-only regular audit,
  explicit version metadata, packaging/privacy checks and immutable
  beta releases with the correct ZIP and SHA-256 checksum.
- **Language migration checks:** inventory checks for untranslated
  Portuguese prose, compatibility tests and an English-source release
  blocker. Code samples and inherited historical identifiers are
  preserved only where scientifically or technically required.

## Installation

Download **MeuArtigoSkill-v0.9.0-beta.1.zip** from this tagged release
and optionally verify it against **SHA256SUMS.txt**. Choose the prepared
Skill archive, not the generic GitHub source-code ZIP. Follow
[Getting started](COMECE-AQUI.md) and the product-specific guide.
ChatGPT, Claude and Gemini availability and permissions vary by
product, plan and account. An imported Skill does not prove database
access, runnable scripts, Google Drive writes or cross-session recovery.

The researcher may start talking naturally in Portuguese without
changing the English source. For example, Portuguese conversation
with an English-language journal manuscript is a supported instruction
pattern, not an empirically certified cross-platform outcome.

## Scientific and operational limitations

Software tests do not prove correct methodology for every question,
independent peer-review quality, causal C.A.D.A. benefits, privacy
compliance for arbitrary source files or flawless response-language
selection across deployed AI models. These empirical and live
end-to-end evaluations remain **pending**. Source copyrights,
researcher decisions and journal policies always apply.
