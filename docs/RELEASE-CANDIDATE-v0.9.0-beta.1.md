# Draft release candidate — proposed v0.9.0-beta.1

**Status: PREPARATION ONLY — NOT PUBLISHED.**
The last public, installable release remains
[v0.8.0-beta.8](https://github.com/rebsonm/MeuArtigoSkill/releases/tag/v0.8.0-beta.8).

This file is a maintainer preparation note. It is not an official
version tag, GitHub Release, peer-reviewed evaluation or promise of
scientific performance. No new release should be created until the
English-source migration is genuinely complete and the secure manual
release workflow has passed.

## Changes already implemented after v0.8.0-beta.8

- **Source and release integrity:** canonical version source,
  read-only mandatory CI, separately authorized manual publication
  that refuses to overwrite prior versions, pinned GitHub Actions,
  license attribution and public-source privacy checks.
- **Method-aware workflows:** distinct integrative/systematic/
  problematizing review, theoretical/conceptual, qualitative,
  quantitative, mixed-method and design-science routes with
  attributable human choice, preserving seven existing
  scientific gates and legacy project records.
- **Epistemic provenance:** clearer boundaries among bibliographic
  identity, literal passage verification, recorded human review
  and actual scientific results; no automatic promotion of
  source metadata into research validity.
- **Progressive Skill context:** a shorter entrypoint and
  conditional method references, with separate MINIMAL/FULL
  presentation and intact substantive controls.
- **Language architecture:** English source code/instructions,
  automatically researcher-language conversations, persistent
  optional explicit locale choice and independent manuscript
  language. Original research quotations and machine-readable
  scientific identifiers remain intact.
- **Source migration guard:** repository inventory and a manual
  publishing block when untranslated Portuguese source prose
  remains.

## Pending before this can become a release

- Faithful English conversion of the remaining current and
  historical repository documents and human-readable
  source-code strings. Preserve bibliographic original titles,
  legal notice text, established API/schema identifiers and
  existing relative links.
- Human editorial review of methodological equivalence.
- Zero substantial untranslated source findings under
  `scripts/audit_source_language.py --strict`;
  this heuristic is only one check.
- Consistent `VERSION`, `CITATION.cff`, README and CHANGELOG
  synchronized **only when actually ready for release**, using
  the real release date, and comprehensive CI/bundle validation.
- Manual creation of a new immutable prerelease and verification
  of its installable ZIP and SHA-256 checksum.

## Scientific limits unchanged

No scientific paper-quality improvement, C.A.D.A. productivity
benefit, real human evaluation or live cross-platform multilingual
performance has been demonstrated by these engineering commits.
Those evaluations remain separately documented as pending.
