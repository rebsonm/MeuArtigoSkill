# RC.5.1 plugin installation

Follow the [quick-start guide](INSTALLATION.md). Download the [published RC.5.1 plugin ZIP](https://github.com/rebsonm/MeuArtigoSkill/releases/download/v1.0.0-rc.5.1/MeuArtigoPlugin-v1.0.0-rc.5.1.zip) and verify its checksum at the [release page](https://github.com/rebsonm/MeuArtigoSkill/releases/tag/v1.0.0-rc.5.1). Install or update through Plugin Creator, not the public directory search. No standalone Skill installer.
