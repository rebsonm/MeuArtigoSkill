# Using Meu Artigo with Gemini

Meu Artigo is a research-support Skill. Whether Gemini can import it or run every supporting function depends on the Gemini product and account available to you.

## Installation

Get the complete prepared ZIP from the [currently published Meu Artigo release](INSTALLATION.md). If your Gemini product supports Skills import, follow its import instructions and choose the prepared Skill package, not GitHub's source-code archive.

See [Google's current Skill guidance](https://support.google.com/gemini/answer/17094296?hl=en) for availability and supported formats.

## What you can expect

Begin by describing your real research question in your preferred language. Meu Artigo should discuss methodological alternatives, organize actual source material and clarify which decisions belong to you.

Do not assume Gemini can execute every script or import every binary file in the package. If a feature is unavailable, the assistant should explain what can still be done with actual accessible documents and tools.

Drive storage must be specifically authorized and writable before being described as the saved location. An alternative requires your express agreement. Access to Scopus, Web of Science and licensed articles is not automatically included.

## Continue a previous article

Ask to continue the existing saved research project. Only accessible original records can establish past decisions and progress; previous chat text is not proof of saved work.

These capabilities have not all been independently tested across actual Gemini accounts. Read [Getting started](COMECE-AQUI.md) and [platform limits](COMPATIBILIDADE-PLATAFORMAS.md).
