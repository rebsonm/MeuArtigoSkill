## Gate 4 — real article, real sources, real researcher decisions

Only perform this gate in an **authorized project workspace** with real,
lawfully accessible source documents. Existing manuscripts may be inspected
read-only as historical examples, but cannot be claimed as a new article
generated from this exact candidate.

Procedure:
1. Freeze the project, journal, date, method route and question.
2. Use genuine bibliographic searches and save verbatim provider-specific
   queries, filters, counters, timestamps and original exports.
3. Confirm eligibility and the final corpus against real source materials,
   preserving disagreements and unavailable full texts.
4. For each material [L] statement inspect its source locator; for [I] expose
   the interpretive warrant; for [P] show nearest works and bounded novelty.
5. Capture real researcher decisions at every required scientific gate,
   including limitations and evidence. No generated or surrogate approval.
6. Prepare a complete manuscript, anonymization review, declared AI use,
   rights check, journal profile, validation reports and final package.
7. Compare outputs with original evidence and document errors and rework.

## Gate 5 — actual ChatGPT installation, resumption and persistence

Do not mark passed until an authorized researcher records:
1. Which ZIP / commit was installed in the real ChatGPT account.
2. Onboarding language and default manual route with all APIs disconnected.
3. At least one valid actual search/import in a researcher-approved project.
4. One failure path (API unavailable) with continuity preserved.
5. Actual Google Drive write permission and verified object ID/readback.
6. Fresh-chat resumption from the canonical `CONTINUIDADE.md`.
7. Genuine C.A.D.A. four-column dashboard and pending scientific decisions.
8. Real controls for anonymization, restricted PDFs, safe export and cleanup.

**Current state: NOT EXECUTED in the user's ChatGPT client.** Passing CI,
the model reading SKILL.md or importing a Python module is not proof of a
successful ChatGPT Skill installation.

## Gate 6 — public scientific claims and outreach boundary

Permitted statements:
- "Meu Artigo is an experimental research-assistance Skill."
- "It records methodological decisions, sources, provenance and AI use."
- "Automated checks have passed on the stated code revision."
- "Independent scientific evaluation is pending."

Not yet permitted:
- "Scientifically validated", "peer-reviewed", "zero hallucinations",
  "automatically writes publishable papers", "works on every platform",
  "complete API integration", "verified productivity gains" or
  "guaranteed journal acceptance".

Ask external experts for *critical feedback*, not endorsement or proof of
effectiveness. Share only anonymized, rights-cleared test materials and a
precise build identifier. Require a separate affirmative decision to
publish or send a beta package.
