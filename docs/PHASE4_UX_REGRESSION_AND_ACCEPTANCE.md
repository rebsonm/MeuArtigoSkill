## Safeguards

- Missing and partial records are unavailable or pending, never invented successes.
- C.A.D.A. is administrative tracking, not scientific validation. A registered approval is not independent identity authentication.
- PLANNED and NOT_EXECUTED searches are not promoted to actual database searches. External providers are not queried by the panel.
- L/I/P counts are recorded labels, not scientific findings or quality percentages.
- No ready-to-submit state is asserted. Preliminary checklist conditions do not cover journal disclosure, outgoing hashes or genuine signed release.
- Recorded snapshots do not prove live Google Drive synchronization; the MCP server currently reads an authorized local mirror only.
- No arbitrary project paths are taken from the iframe/model. Symlink escapes of canonical CSV files are rejected.
- Project-title fallback no longer leaks a local folder name. Failure clears stale dashboard state. UI uses DOM text nodes, not HTML injection.
- The visual header embeds the original assets/icon.svg design. No new artwork or made-up status is bundled.
- The owner screenshots are illustrative and cannot be used as live source values.
