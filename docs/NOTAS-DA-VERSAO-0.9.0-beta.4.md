## Release boundary

The Skill has seven researcher-controlled scientific gates. Automated tests are engineering checks using controlled/synthetic inputs, not proof of academic quality, independent reviews or genuine external search execution.

No new Skill release is published by these source changes. A future release requires explicit approval, a checked installation archive and a SHA-256 manifest.
