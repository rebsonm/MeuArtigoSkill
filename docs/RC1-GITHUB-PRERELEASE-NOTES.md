# Meu Artigo v1.0.0-rc.1 — experimental prerelease

This is an **experimental software release candidate**, not a stable version or independent scientific validation.

## Assets

- `MeuArtigoSkill-v1.0.0-rc.1.zip` — installable Skill.
- `MeuArtigo-PDFs-51-attributed.zip` — all **51 third-party academic PDFs** already published in the GitHub main source tree, with `PDF-ATTRIBUTIONS.md` and `pdf_catalog.json`. No private Drive PDF or unpublished source collection is included.
- `SHA256SUMS.txt` — SHA-256 hashes of both archives.

The repository also publishes **475 bibliographic [P] source cards** and **174 editorial [I]/[P] methodology cards**. Bibliographic leads and editorial interpretations do not count as independently verified literature evidence [L].

## Installation and scope

Install **only the Skill ZIP** in a compatible assistant. The PDF library ZIP is a reference collection, not an installable Skill. Each researcher connects their own authorized storage; installing Meu Artigo never grants access to the maintainer's private Drive. A GitHub release does not approve scientific methods, literature claims or publication of any manuscript.
