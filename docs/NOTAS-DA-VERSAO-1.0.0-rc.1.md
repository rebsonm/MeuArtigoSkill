# Meu Artigo v1.0.0-rc.1 — release-candidate acceptance notes

**RELEASE CANDIDATE ONLY — NOT PUBLISHED. NOT A STABLE RELEASE.**

This source candidate consolidates the changes proposed in PRs #95, #96
and #97 with the defensive review in PR #98 and selective Skill-only
hardening proposed in PR #100. No main-branch merge,
public GitHub tag, final release, platform installation or independently
verified researcher evaluation follows from creating this candidate.

## Changes available for testing

- The standalone Skill provides read-only previews of changes to
  quantitative inference aims and fields across eight methodological routes.
  Potential consequences remain review prompts, not verified dependencies
  or automatic scientific judgments.
- Research continuation can present a single recorded next step,
  why it is suggested, and a proposed evidence-based exit criterion.
- The conservative repeated-attempt warning considers hash-linked local
  execution receipts and current script and artifact state before suggesting
  that a repeated operation should be diagnosed rather than retried blindly.
- A missing Drive folder produces a mandatory parent-check request,
  not permission to create it. An offline create-once guard detects
  ambiguous attempts, but **remote creation remains blocked** without
  authenticated host scope, complete pagination and durable audit readback.
- A compact HTML view explicitly labels partial gate lists; the total
  recorded human approvals is never inferred from the visible subset.
- Development CI scans tracked source files for possible secrets and does
  not include that developer-only utility in the installed Skill.
- The historical record, human-controlled scientific checkpoints,
  local/Drive permission boundary and distinction between source evidence,
  interpretations and propositions remain in force.

## Candidate package and intended tests

The release audit can assemble an installable
`MeuArtigoSkill-v1.0.0-rc.1.zip` and a matching
`SHA256SUMS.txt` as temporary GitHub Actions artifacts attached to
the development PR's CI run. These are test materials, **not** a GitHub
Release and not an official recommended download. A repository source-code
archive is not the prepared Skill installer.

Before a stable v1.0.0 release, verify a fresh real-host Skill import,
the active installed version, correct research resumption and no duplicated
researcher decisions, human gate preservation, honest errors for unavailable
Drive permissions and bibliographic access, and no critical regression.
Record the platform, steps, observed outcome and known limitations.
No confidential researcher data is required for acceptance.

## Exclusions and unresolved evidence

- No separately hosted service, remote account integration, authenticated UI panel,
  account connector or infrastructure deployment is supplied by this ZIP.
- No real ChatGPT, Claude or Gemini installation has been proven for this
  candidate merely by passing simulated tests or building the archive.
- No independent scientific validation, field-study result, measured
  productivity improvement or manuscript originality is asserted.
- A source candidate does not replace the published v0.9.0-beta.6
  release; its tag, assets and checksum remain unchanged.
- The stable publishing pathway requires later maintainer approval and
  verification. The beta-specific publisher must not be used for this RC.

Use the [official published beta.6](https://github.com/rebsonm/MeuArtigoSkill/releases/tag/v0.9.0-beta.6)
for the current public installer until a newer release is independently
verified on GitHub.
