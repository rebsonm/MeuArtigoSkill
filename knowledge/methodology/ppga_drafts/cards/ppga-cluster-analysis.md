## Method selection question

Are groups a useful exploratory representation rather than a prespecified truth?

## Proposed methodological decision logic [P]

Define distance or similarity, standardization, feature choice, algorithm and the reason for grouping.

## Checks before committing to this strategy

Assess sensitivity, cluster stability, outliers, interpretability and whether groups are actionable.

## Falsification / boundary example

An algorithmic cluster label is not itself a validated population category.
