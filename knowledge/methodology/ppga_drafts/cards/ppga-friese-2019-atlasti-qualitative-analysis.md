## Methodological decision question

Which analytic decisions should remain explicit when software organizes transcripts or codes?

## Independent decision guidance

Specify the analytic approach first, then use software for organizing excerpts, tracing code revisions, memos and transparent exports. Tool affordances do not substitute for theory or interpretive judgment.

## Researcher checks and falsification opportunities

Preserve versioned coding decisions, source excerpts, analyst disagreements when relevant, and reproducibility limits.

## Competing design / counterexample
