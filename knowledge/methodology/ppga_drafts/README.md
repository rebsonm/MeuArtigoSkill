# PPGA methodology draft intake

This directory contains **staged source-specific methodology card candidates** prepared from a PPGA course-library inventory. It is intentionally separate from `knowledge/methodology/cards/` and `catalog.json`: these are **not** part of the 174 active editorial cards or 475 existing bibliographic prospecting cards.

For cards marked PARTIAL_DIRECT_READING, only named source sections or course slides were accessed. All others are metadata-only [P] prompts. No source PDF, direct quotation, private Drive identifier, paid chapter, classroom slide or publisher figure is republished. Each candidate requires edition-level source verification and two distinct reviews (rights/originality and scientific/editorial fidelity) before any promotion.

See [intake and coverage ledger](./PPGA-METHODOLOGY-INVENTORY-2026-11-22.md). Researcher-controlled scientific gates and decisions remain unchanged.
