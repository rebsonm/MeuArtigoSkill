# Methodological source consultation registry (475 records)

**Scope and limits.** These **475 per-source bibliographic prospecting cards** were generated from a user-selected scientific file inventory and its bibliographic matching ledger. **They are NOT 475 independently researched methodological syntheses.** An identified title or bibliographic spreadsheet match does not show that the underlying PDF was examined, does not provide publication permission, and cannot ground a claim [L]. They are an opt-in navigation layer for a publicly installable Skill.

- 475 original archive records have a distinct searchable ID and a transparent consultation card.
- 404 have a candidate title associated with the bibliographic catalogue; 71 lack a reconciled title.
- 3 ledger items record some direct-source reading; this does not mean 475 PDFs were read.
- Only documents listed as individually license-reviewed in `knowledge/methodology/pdf_catalog.json` may be redistributed as source PDFs.
- Independently authored methodological syntheses are kept separately in `knowledge/methodology/cards/`; don't count these registry files as reviewed academic cards.
- All registry cards contain **original editorial consultation QUESTIONS and decision cautions [P]**, based on the classification field, NOT alleged summaries of any particular author's results.
- No private Drive IDs, stored PDFs, remote tokens, restricted full texts or user documents are bundled.

Catalogue: `knowledge/methodology/source_registry_catalog.json`. The optional read-only client must enforce exact Git commit, strict source-card hash and restricted metadata-only evidence labels.
