## Intended methodological question

When can a chatbot help qualitative analysis without hiding how an algorithm shapes researcher interpretation?

## Original editorial guidance

Treat model responses as situated generated suggestions rather than observations or expert participants. Record prompt version, model context, data supplied, interpretive use and the researcher's substantive acceptance or rejection.

## Decision checks for the researcher

Examine privacy authorization, prompt sensitivity, run variation, algorithmic bias, missing interpretations, researcher's role and transparent methodological disclosure.

## Limitations and counterevidence

An AI-produced code or theme cannot substitute for original source evidence. Copyright, confidentiality and ethics restrictions on inputs remain in force.
