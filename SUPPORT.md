# Meu Artigo — Support

Meu Artigo is an experimental, free research workflow plugin maintained by Rebson de Morais Mendes.

- Project documentation: https://github.com/rebsonm/MeuArtigoSkill
- Channel for questions and bug reports: https://github.com/rebsonm/MeuArtigoSkill/issues

Include the plugin version, host environment, steps to reproduce, and a sanitized description of expected and observed behavior. Never post passwords, API keys, confidential manuscripts, personal data, or restricted research materials. Support does not replace scientific supervision or independent methodological review.
