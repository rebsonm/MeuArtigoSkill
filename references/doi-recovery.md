# Missing DOI and abstract recovery — conservative provider sequence

Apply to imported records, prior to corpus freeze where relevant, and before citation audit. Preserve original DOI/title/author/year/journal and database occurrence; store candidate and result in existing record/trace/verification fields or SOURCE_VERIFICATION.json. Do not replace a conflicting DOI or exclude a record just because DOI is absent. Use only bibliographic metadata in external queries, not unpublished manuscript text.

1. Normalize provided DOI and verify registry identity using Crossref lookup first for Crossref-registered records; compare title, first author, year and venue. For other registries follow DOI resolver, DataCite or publisher. A DOI resolving alone is insufficient. Keep distinct preprint/version/erratum and publication records.
2. Missing DOI: query Crossref by bibliographic title + author + year (public web or authorized network executor). Use bounded search from bibliographic_connectors.py or doi_recovery.py when executable. Query OpenAlex and/or Semantic Scholar for unmatched, conflicting or ambiguous records. Use Consensus/Scite/SciSpace to discover possible publications and citation context; these are not authoritative DOI registries. Never represent their output alone as confirmed DOI.
3. Confirm candidates against registry and original publisher/DOI landing page; Firecrawl or native web retrieval can fetch public metadata. Compare material fields, document mismatches (including online-first dates) and request human review for ambiguity. A local score is triage only; never automatic scientific approval. Record source, timestamp, query, candidate, status and actual evidence locator. Use MATCH_CANDIDATE, AMBIGUOUS, CONFLICT, NOT_FOUND, UNVERIFIED, or VERIFIED_IDENTITY only after actual corroboration. A legitimate source without DOI may be manually verified using other identifiers/publisher records.
4. Missing abstract: consult indexed metadata, publisher, Crossref if abstract provided, OpenAlex/Semantic Scholar, recognized repositories, then lawful full text via Unpaywall/Firecrawl/web. Mark ABSTRACT_RECOVERED only when actual abstract text and provenance obtained. A generated summary, snippet or introduction is NOT an author abstract. Record language and access level; never convert abstracts into full-text claims. Preserve missing states and rights.
5. Process batches with a resumable queue, cache same DOI within authorized project, respect quotas, use bounded retries and fallback providers. Persist after each real batch; report actual coverage and remaining queue. No credentials in chat/logs and no bypass of paywalls. Technical failure is not absence. Do not change human inclusion decisions. Existing verify_sources.py checks metadata and locators; claim_integrity.py handles evidence linkage, not semantic validation.
