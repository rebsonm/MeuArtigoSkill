# Stage 13 — REG-013 diagnostics and REG-001/019 replay

## Scientific authority and provenance
- REG-013 performs read-only structured reference and human-declared
  claim triage. An objective documentary contradiction is a technical BLOCK;
  a lexical or contextual warning is only ADVISORY. None of these scores
  validates the scientific content, a human identity, or one of seven gates.
- REG-001 tracks synthetic software tests in a chained local JSONL ledger.
  Its sha256 chain detects inconsistency, but is not a digital signature,
  trusted timestamp, independently authenticated observation, or peer review.
- REG-019 exports a deterministic, redacted ZIP with a synthetic case
  catalog, protocol, hashed observations and per-member SHA-256 manifest.
  Hash replay recomputes scores from provided test observations; the raw
  private source passages and references are not shipped as evaluation data.
  The redacted archive alone cannot reverify original ledger attestations.
- ZIP publication uses a same-directory exclusive hard link, not an
  overwrite-capable os.replace. The optional report writer allows only
  explicit create-only local reports beneath 98_Technical_Reports.

## UI separation
- scientific_panel_projection reads REG-013, then whitelists counters,
  status and code-only findings. All missing/invalid input is presented as
  INPUTS_UNAVAILABLE with null numeric counters (never synthetic zeros).
- The native panel reuses the projection. The blue research site receives
  only sanitized fields and displays objective issues separately from
  semantic advisories. The browser has no independent scientific decision
  engine. It never receives article passages, reviewers or local paths.
- Missing human approvals, source verification and authorization always
  remain human decisions. DEC/TRACE, C.A.D.A., Drive F1-F9 and OAuth
  controllers have not been modified by the scientific features.

## Validation and limits
Synthetic suites cover missing inputs, malformed attestations, XSS in
finding codes, private-text leakage, deterministic replay, hash tampering,
original-source provenance conflicts and conflicting ZIP output ownership.
These tests are engineering validation, not estimates of accuracy,
external validity, sensitivity, specificity, fairness or research impact.
The "held-out" frozen synthetic benchmark is NOT a fresh prospective blinded
study; authorship, detector rules and case selection may bias observed metrics.

No merge, release, plugin update, VPS access or Google Drive write is
allowed at this stage.
