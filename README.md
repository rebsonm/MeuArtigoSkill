# Meu Artigo — historical branch

This branch is kept only as a record of earlier development. It is **not the current installation source** and should not be used for new installations or user instructions.

For the active, public research **Skill**, see the [current README on main](https://github.com/rebsonm/MeuArtigoSkill/blob/main/README.md) and the [Skill installation guide](https://github.com/rebsonm/MeuArtigoSkill/blob/main/docs/INSTALLATION.md).

The [published Skill releases](https://github.com/rebsonm/MeuArtigoSkill/releases) contain the prepared installation archives. A branch source-code ZIP is not the user installation archive.

Historical commits and previously published archives are retained for provenance and can differ from the current Skill distribution.
