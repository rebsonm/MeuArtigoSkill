**A research and writing Skill for scientific articles, with verifiable evidence, documented continuity, and human scientific decisions.**

Meu Artigo helps a researcher move from a research problem to a reviewable article through method-appropriate steps. It distinguishes **[L]** consulted literature, **[I]** defensible inference, and **[P]** original propositions. C.A.D.A. tracks administrative tasks without confusing task completion with scientific validity. **Seven scientific gates** remain controlled by real researcher decisions.

## Getting started

1. **[Download the official Skill beta.1 ZIP](https://github.com/rebsonm/MeuArtigoSkill/releases/download/v0.9.0-beta.1/MeuArtigoSkill-v0.9.0-beta.1.zip)**. Choose this prepared asset rather than GitHub's **Code → Download ZIP**, which contains the development source tree.
2. Use the **Skills / Habilidades** import provided by your assistant or install the Skill as a supported local directory. Availability depends on the account and platform.
3. Ask: *"Quero iniciar um artigo científico com Meu Artigo; primeiro verifique as conexões e o armazenamento."*
4. Authorize and verify actual storage before substantive research. Account connection, Python execution and access to paid bibliographic sources are separate capabilities.

## What the Skill supports

- **Question and method:** define a research question and design, preserving the researcher's original problem.
- **Sources and evidence:** organize verifiable searches and metadata, honest full-text access, inclusion/exclusion decisions and [L]/[I]/[P] claims.
- **Science governance:** seven human-reviewed gates, trace IDs, immutable-purpose snapshots, evidence and ethical boundaries.
- **C.A.D.A. administrative organization:** Capture, Assign, Define a deadline, and Track verifiable next actions.
- **Journal-aware manuscript:** official journal requirements, rights, anonymization, disclosure and pre-submission checks.
- **Continuity and task tracking:** preserve `CONTINUIDADE.md`, authorized project records and C.A.D.A. responsibilities without inventing prior actions.

The default storage policy is `GOOGLE_DRIVE_FIRST`: access **and write capability must be verified** before any canonical work is claimed. A local fallback requires explicit researcher authorization. A previous project's data or sources cannot silently become another project's corpus.

## Scientific honesty and platform limits

The Skill is **experimental beta** research-support software, not an independently validated scientific research method. It does not invent literature, searches, empirical results, source passages, third-party rights, human approvals or actual submission. Script execution, Google Drive access and publisher services must be demonstrated with receipts in the actual environment.

The source repository contains operational scripts, methodological references and **software tests for the Skill**. Prepared installation archives exclude development tests; they include `SKILL.md`, appropriate documentation and selected operational helpers.
