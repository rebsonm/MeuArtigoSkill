# Installation

## Recommended public beta

**v0.9.0-beta.5** is a *published experimental GitHub pre-release*, not a stable release.

- [Download the installable Skill ZIP](https://github.com/rebsonm/MeuArtigoSkill/releases/download/v0.9.0-beta.5/MeuArtigoSkill-v0.9.0-beta.5.zip)
- [Download SHA256SUMS.txt](https://github.com/rebsonm/MeuArtigoSkill/releases/download/v0.9.0-beta.5/SHA256SUMS.txt)
- [Read release notes](https://github.com/rebsonm/MeuArtigoSkill/blob/main/docs/NOTAS-DA-VERSAO-0.9.0-beta.5.md)

Do **not** choose `Code → Download ZIP` or the autogenerated `Source code (zip)`: those are repository snapshots, not the prepared installer.

## Installation procedure

1. Download the prepared ZIP from the tagged release, with its matching SHA-256 checksum file.
2. If needed, verify the ZIP SHA-256 against `SHA256SUMS.txt`.
3. Import the ZIP into an assistant **only if your account actually supports importing Skills**. For local-directory installation, unpack while keeping `SKILL.md` at the Skill root.
4. Start a fresh conversation and ask the assistant to verify actual capabilities and authorized storage.
5. If an existing research project is selected, resume from its canonical records before proposing new work.

Expected package root includes `SKILL.md`, `agents/`, `references/`, `scripts/`, `docs/` and release metadata. Development tests are not part of the end-user package.

### Verify a checksum locally (optional)

On macOS/Linux, from a folder containing the ZIP and its checksum file:

```bash
sha256sum -c SHA256SUMS.txt
```

On Windows PowerShell, you may compute the digest using:

```powershell
Get-FileHash .\MeuArtigoSkill-v0.9.0-beta.5.zip -Algorithm SHA256
```

Compare the resulting hexadecimal digest to the published checksum. A hash check protects file integrity; it does not establish scientific validity.

## Distinguish independent capabilities

| Capability | What needs actual verification |
| --- | --- |
| Skill import | Platform and account actually accept the package |
| Drive storage | Authenticated read, write and relevant confirmation of persistence |
| Python helpers | Execution actually available in the environment |
| Scopus/Web of Science | Actual entitlement, access, query and retrieved output |
| External publishing | Authorized journal action plus an actual receipt |

These checks must not be inferred from the Skill's installation alone. If Drive cannot be verified, obtain **explicit consent** before using the designated local/Work fallback.
