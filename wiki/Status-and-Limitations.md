# Status and limitations


> **Last planned experimental beta: `v0.9.0-beta.6` (release preparation, 2026-10-15).** The cumulative continuity, conversational resume and safe blocker guidance update is documented in [beta.6 release notes](https://github.com/rebsonm/MeuArtigoSkill/blob/main/docs/NOTAS-DA-VERSAO-0.9.0-beta.6.md). **Beta.5 remains the latest published installer until GitHub actually publishes beta.6 and its checksum.** This last-beta designation is a plan, not stable certification; the project-owned MCP service and MCP Apps UI are not live-validated. Existing installations do not auto-update.

The PR #70 engineering candidate passed 758 regressions, 11 synthetic integrated scenarios and eight fictional research journeys before version bump. Live custom MCP/OAuth/visual UI and independently reviewed scientific usability are **not yet demonstrated**.

> **Publication status:** [v0.9.0-beta.5](https://github.com/rebsonm/MeuArtigoSkill/releases/tag/v0.9.0-beta.5) is the **recommended published experimental beta** (October 14, 2026), with its installable ZIP and checksum available. It is not a stable or scientifically validated release. Installed Skills do not automatically update.

## What is available

- A **published experimental [beta.5 release](https://github.com/rebsonm/MeuArtigoSkill/releases/tag/v0.9.0-beta.5)** with its prepared Skill installer and checksum.
- A versioned scientific contract, route-specific references, C.A.D.A. workflow, continuity and provenance controls.
- Deterministic software tests and developer-facing audits in the source repository.
- Documentation for supported/possible platforms, manual source workflows, lawful rights handling and user feedback.

## Beta.5 initializer correction

The scientific project core is checked before optional XLSX generation. If the visual spreadsheet stalls, the initializer records the problem without treating incomplete or invalid research documents as successful initialization. Users should report actual failures through GitHub Issues. This is an engineering correction, not a completed empirical usability evaluation.

## What is **not** established by the release

- Independent scientific validation of the Skill or a complete research methodology.
- Demonstrated causal improvements in productivity, article quality or administrative efficiency from C.A.D.A.
- Actual external user studies, a verified complete article evaluation or universal journal compliance.
- Verified end-to-end execution on every assistant or live multilingual compatibility.
- Access to paid databases, private full text, Google Drive authorization or submission on behalf of an individual user.
- Proof of source quality, human identity or scholarly originality merely from passing software tests.

**Engineering regression tests are not equivalent to a field study.** A local action receipt is not independent evidence of an external provider's action. The project must continue marking pending evaluations as **PENDING** until actually completed and documented.

## Contributions and feedback

Voluntary beta feedback should report reproducible behavior and avoid personal/confidential materials. Claims made for a specific installed account, tool connection or completed scientific gate must be supported by the actual session's observed results.
